Pilulier — la planche de style

Une seule règle porte tout le reste : app.css ne contient aucune valeur brute. Couleurs, corps, filets, rayons, durées, et jusqu'à la casse des micro-libellés viennent de theme.css. Cette planche est engendrée par le code : ce qu'elle montre est ce que l'application affiche.

Graphiques — les formes d'une référence, la matière de la planche

Lignes à bouts ronds, barres en gélules, aires courbes, anneau fendu, nœuds ronds : les formes viennent d'une référence monochrome. Les dégradés, eux, sont remplacés par la hachure — la seule matière que la planche autorise. Et dans un pilulier, une barre est une gélule : elle se remplit à mesure que les prises sont validées.

Icônes — toutes tracées par le code, aucune image

Ce que le style interdit Aucun arrondi. Aucune ombre. Aucun dégradé décoratif. Aucune image, aucun jeu de pictogrammes importé, aucune police distante. Aucun emoji — les statuts s'écrivent [x] [!] [-] [ ]. Aucune couleur qui ne porte pas d'information. Aucun mouvement qui n'annonce pas un changement d'état.
